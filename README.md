# gas-pressure

가스 실린더 압력 센서 표시값을 실제 압력(레귤레이터 게이지)에 맞추는 보정 계산기. Python 3 표준 라이브러리만 씁니다.

## 모바일 앱 (PWA)

`index.html` + `manifest.webmanifest` + `sw.js` + 아이콘 파일이 설치형 웹 앱입니다.

- 계산 탭: 0점·스팬 두 측정점으로 새 최저·최대 설정값 계산, "설정했음 → 반영"
- 기록 탭: 보정 결과를 메모와 함께 폰에 저장, CSV 복사·저장
- **https 주소**로 열고 Chrome ⋮ → "앱 설치"(또는 "홈 화면에 추가")를 하면 아이콘이 생기고, 주소창 없이 전체 화면으로 열리며, 한 번 연 뒤에는 오프라인에서도 동작합니다.
- `index.html` 파일 하나만 폰에 받아 열어도 계산·기록은 됩니다 (설치·오프라인 캐시만 안 됨).
- 앱 파일을 고치면 `sw.js` 의 `VERSION` 을 올려야 설치된 폰에 새 버전이 들어갑니다.

## 센서 최대값 보정 (주 기능)

실제 압력과 센서 표시값을 넣으면 맞춰야 할 **센서 최대 설정값**을 알려 줍니다.

```
python gas_pressure.py                         # 대화형: 지금 설정 최저·최대, 실제 압력, 표시값 입력
python gas_pressure.py --max 150 --fix 120 88  # → 새 최대 설정값 204.5 bar
```

새 최대 = 최저 + (실제 − 최저) × (지금 최대 − 최저) ÷ (표시 − 최저)

- 0점(최저)이 맞다는 가정입니다. 0 bar 에서 표시가 0 이 아니면 0점부터 맞추세요.
- 설정을 바꾼 뒤 다시 확인할 때는 `--max` 에 바꾼 값을 넣습니다.

## 보정식 (gain/offset)

```
python gas_pressure.py --range 0 150 --point 120 88       # 1점 보정 (오프셋 0 가정)
python gas_pressure.py --point 0 0.4 --point 120 88 --read 60 75   # 2점 보정 + 환산
```

- `--range LO HI` : 센서에 설정된 범위 (기본 0 150)
- `--point 실제 표시` : 기준점, 최대 2개
- `--gauge-max` : 레귤레이터 게이지 최대 (기본 120)
- `--read` : 실제 압력으로 바꿀 표시값들

보정식과 함께, 표시값 비율로 역산한 센서 실제 범위와 가까운 정격 범위를 보여 줍니다.
범위 설정이 틀렸다면 보정식보다 설정 범위를 고치는 게 먼저입니다.
